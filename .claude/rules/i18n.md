# Rule: i18n-ready (mandatory)

Every **new** UI string goes through the internationalization layer, never
hardcoded inline.

- Layer: `src/editor/i18n.ts`, with `t(key)` (and `t(key, { var })` to
  interpolate `{var}`) plus a dictionary.
- New strings are added to the `en` dictionary and referenced with `t()`.
- Existing strings still hardcoded are migrated to `t()` **incrementally**.
- The default language is **English**; the goal is to be able to add languages
  without a refactor.

## When closing a feature

Verify that no new UI string was left hardcoded: all go through `t()` and exist
in the dictionary.

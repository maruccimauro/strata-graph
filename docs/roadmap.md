# Roadmap

Current status and what's next. The full engineering backlog lives in
[`../BACKLOG.md`](../BACKLOG.md).

## Done

Connected scan · banded dependency graph · floating edges (border-attached) ·
drag + persistence · manual nodes/edges with a direction dialog · comments ·
node & edge overlays (flags, open file/folder, section, delete) · undo/redo ·
live theme · preferences · PNG export · box-select · cross-platform server.

## Next

- Bands that auto-grow to their content; vertical ↔ horizontal layout.
- Overlay action bars (node + multi-select), node lock, creation/due dates.
- Middle-click pan; right-click context menus; richer connector management.
- Create-edge panel (direction + section filter + node), section search.
- Preferences as a sidebar-category panel.
- (later) MCP-style command interface for AI control.

See the tracker for the authoritative, per-item status.

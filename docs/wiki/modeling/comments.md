# Comments

Comments are sticky notes you attach to the graph. They are not dependencies.

## What a comment is

A **comment** is a distinct kind of node, drawn like a sticky note so it never reads as part of the dependency structure. It carries a title, an optional description, and an optional reference.

Its connector is drawn differently from a dependency edge: a comment link has no direction or dependency meaning.

## Add a comment

From a node's overlay, choose **🏷️ Comment**. You are asked for a title and an optional description. The comment appears next to the node, linked by a comment connector.

## Comment links

You can also create a standalone comment link between two nodes: drag to connect and choose **Comment link (no dependency)** in the direction dialog. See [Edges](/modeling/edges).

::: info
Comments are always manual, so you can delete them from their overlay like any manual node.
:::

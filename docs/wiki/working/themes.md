# Themes

Strata has a light and a dark theme.

## Toggle

Use **◐** in the toolbar or **View ▸ Toggle theme**. Your choice is saved and applied before the first paint next time, so there is no flash.

## How it works

Flat interface colors are CSS variables, so the base theme switches instantly. Per-section colors are computed from each section's hue for the current theme and rebuilt when you toggle, so bands and accents stay readable in both light and dark.

::: info
Section bands use stronger colors in both themes than a faint tint, so the grouping stays clear without drowning the nodes.
:::

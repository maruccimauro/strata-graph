# Exporting

Strata exports your work two ways: as a model file and as an image.

## Export a model (.sgm)

**File ▸ Export model (.sgm)** downloads the whole graph as a [Strata Graph Model](/models-data/strata-graph-model). Use it to back up, share or version-control a graph. Reopen it with **File ▸ Import model (.sgm)**.

## Export a PNG

**File ▸ Export PNG** (or **⇩ PNG** in the toolbar) renders the whole diagram to a PNG image, framed to fit the content, on the current theme's background. Use it for a quick picture to drop into a document or chat.

## Which to use

- **.sgm** when you want to keep editing the graph later: it is the full, reopenable document.
- **PNG** when you only need a snapshot to look at or share.

# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| <kbd>N</kbd> | Add node |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Esc</kbd> | Close overlays, dialogs and selection |
| <kbd>Shift</kbd> / <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + click | Add to / remove from selection |
| Middle-drag | Pan the canvas |
| Wheel | Zoom |

::: info
<kbd>N</kbd> is ignored while you are typing in a text field, so it will not fire from inside a panel input.
:::

# Keyboard shortcuts

| Shortcut | Action |
|---|---|
| <kbd>N</kbd> | Add node |
| <kbd>Delete</kbd> / <kbd>Backspace</kbd> | Delete the selected edge |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Y</kbd> / <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> | Redo |
| <kbd>Esc</kbd> | Staged: close the open overlay or dialog; press again to clear the selection |
| <kbd>Shift</kbd> / <kbd>Ctrl</kbd> / <kbd>Cmd</kbd> + click | Add to / remove from selection |
| Double-click | Open the overlay of a node or edge (sticky) |
| <kbd>Alt</kbd> + hover | Open a transient overlay on the node or edge under the pointer |
| Right-click | Open the context menu for the background, a node, or an edge |
| Middle-drag | Pan the canvas |
| Wheel | Zoom |

::: info
<kbd>N</kbd> is ignored while you are typing in a text field, so it will not fire from inside a panel input.
:::

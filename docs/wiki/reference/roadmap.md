# Roadmap

Where Strata is and what is next. The authoritative, per-item status lives in the repository's `BACKLOG.md`.

## Done

Banded dependency graph with floating, border-attached edges · drag and position persistence · manual nodes and edges with a direction dialog · the Connect panel · comments · node and edge overlays with an icon action bar · node lock, creation date and due date with a live countdown · multi-selection with a shared action bar · border-safe overlays · undo/redo · live theme · preferences · PNG export · box-select · middle-click pan · Strata Graph Model (.sgm) import/export · configurable data folder · cross-platform Connected server.

## Planned

- Bands that auto-grow to their content; a vertical ↔ horizontal layout toggle.
- More than four connection points per node; richer connector management.
- A starter picker and more built-in models.
- A preferences panel with sidebar categories.
- (later) An MCP-style command interface so an AI can drive the editor.
